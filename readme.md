# EXPO RACE - 万博PLATEAU散策 & ドローンレースゲーム 

2025年大阪・関西万博会場の3D都市モデル（Project PLATEAU）を活用した、3D散策＆ドローンレースゲームです。
プレイヤーは空飛ぶドローン（フライングタクシー）を操縦し、大屋根リングや各パビリオンが立ち並ぶ広大な万博会場を自由に飛行・散策できるほか、設置されたリングコースをくぐり抜けてタイムを競うドローンレースを楽しめます。

自作のDirectX 11ゲームフレームワーク上で動作し、航空写真オルソ床、LOD2タイル、詳細なLOD3近景パビリオン群の非同期ストリーミング描画を実現しています。

## 初回セットアップ（万博アセット）

`expogame.exe`初回起動時にアセットダウンロードが入ります。内容を確認して`AGREE`と入力してください。
公式配布元からのダウンロード、ゲーム用GLBへの変換、`asset/expomodel/`への配置が行われます。
同意しない場合はアセットを取得しません。ダウンロードした公式ZIPや生成物は再配布しないでください。

## ゲームの遊び方

- **会場散策**: 空飛ぶドローンを操作し、広大な万博会場や大屋根リング、パビリオン群を自由に飛び回ることができます。詰まったときはゲーム内メニューの「スタート地点へ戻る」で出現位置へ戻ります。
- **ドローンレース**: ゲーム内メニューの「レース開始」からコースを選ぶとスタート地点へ移動します。カウントダウン後にリングを順番にくぐり抜け、ゴールタイムを競います（リング通過時に加速ブーストがかかります）。
- **コース作成**: ゲーム内メニューの「コース編集・追加」から「コース追加」または既存コースを選び、飛行中に`P`で位置を追加します。`U`で最後の位置を取り消し、メニューから保存します。新規コース名は自動生成されます。メニューはクリックまたは矢印キー / 十字キーで操作し、決定は`Enter` / パッドAです（飛行の`W`や`Space`、左スティックでは操作しません）。
