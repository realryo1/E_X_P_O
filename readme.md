# 万博PLATEAU散策 & ドローンレースゲーム (expogame)

2025年大阪・関西万博会場の3D都市モデル（Project PLATEAU）を活用した、3D散策＆ドローンレースゲームです。
プレイヤーは空飛ぶドローン（フライングタクシー）を操縦し、大屋根リングや各パビリオンが立ち並ぶ広大な万博会場を自由に飛行・散策できるほか、設置されたリングコースをくぐり抜けてタイムを競うドローンレースを楽しめます。

自作のDirectX 11ゲームフレームワーク上で動作し、航空写真オルソ床、LOD2タイル、詳細なLOD3近景パビリオン群の非同期ストリーミング描画を実現しています。

## 初回セットアップ（万博アセット）

GitHubのソースには、万博由来のモデルを含めていません。clone後にPython 3.10以降、
Node.js 18以降を用意し、プロジェクトルートで次を実行してください。

```bat
tool\download_expo_assets.bat
```

公式データの利用条件が表示されるため、内容を確認して`AGREE`と入力すると、
公式配布元からのダウンロード、ゲーム用GLBへの変換、`asset/expomodel/`への配置が行われます。
同意しない場合はアセットを取得しません。ダウンロードした公式ZIPや生成物は再配布しないでください。

GitHub ActionsのリリースZIPにも万博モデル本体は含まれません。リリースZIPを利用する場合も、
展開後の`tool\download_expo_assets.bat`を実行してからゲームを起動してください。

## ゲームの遊び方

- **会場散策**: 空飛ぶドローンを操作し、広大な万博会場や大屋根リング、パビリオン群を自由に飛び回ることができます。
- **ドローンレース**: ゲーム内メニューからコースを選択して決定するとスタート地点へ移動します。カウントダウン後にリングを順番にくぐり抜け、ゴールタイムを競います（リング通過時に加速ブーストがかかります）。
- **コース作成**: ゲーム内メニューで新規作成または編集を選び、飛行中に`P`で位置を追加します。`U`で最後の位置を取り消し、メニューから保存します。新規コース名は自動生成されます。
